# AI Learning Paths

## Path 1: ML Engineer (6 months)
| Week | Topic | Resources |
|------|-------|-----------|
| 1-2 | Python & NumPy | Basics → Data manipulation |
| 3-4 | Statistics & Probability | Distributions, hypothesis testing |
| 5-8 | Classical ML | Linear/logistic regression, SVM, trees |
| 9-12 | Deep Learning | CNNs, RNNs, Transformers |
| 13-16 | MLOps | Docker, MLflow, model serving |
| 17-20 | Specialization | NLP or Computer Vision |
| 21-24 | Portfolio Projects | End-to-end ML applications |

## Path 2: AI Product Manager (3 months)
| Week | Topic | Focus |
|------|-------|-------|
| 1-4 | AI Fundamentals | Understand ML concepts without coding |
| 5-8 | Product Strategy | RICE framework, user research, metrics |
| 9-12 | AI Ethics & Governance | Bias, fairness, responsible AI |

## Path 3: Prompt Engineer (2 months)
| Week | Topic | Skills |
|------|-------|--------|
| 1-2 | LLM Basics | Tokens, context windows, temperature |
| 3-4 | Prompt Techniques | Few-shot, chain-of-thought, RAG |
| 5-6 | Advanced | Function calling, agents, tool use |
| 7-8 | Production | Evaluation, guardrails, monitoring |

## Path 4: Data Scientist (4 months)
| Week | Topic | Tools |
|------|-------|-------|
| 1-4 | Data Analysis | Pandas, SQL, visualization |
| 5-8 | Statistical Modeling | Scipy, statsmodels, A/B testing |
| 9-12 | Machine Learning | Scikit-learn, XGBoost |
| 13-16 | Communication | Dashboards, storytelling with data |

## How to Choose
- **Love coding?** → ML Engineer
- **Love strategy?** → AI PM
- **Love language?** → Prompt Engineer
- **Love insights?** → Data Scientist
